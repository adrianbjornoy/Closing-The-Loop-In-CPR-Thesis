# Closing the Loop in CPR – Master's Thesis Repository

This repository contains the complete source code and analysis pipeline for the Master's thesis on **Closing the Loop in CPR: Real-time Feedback Systems for Improved Compression Quality**. It includes the design and implementation of multiple feedback prototypes, a test framework for conducting structured CPR trials, and a suite of tools for processing and visualizing both objective and subjective performance data.

The goal of this thesis was to evaluate how different types of feedback (visual, auditory, haptic) impact CPR performance and user experience. The work spans hardware/software development, experimental design, and data-driven analysis.
